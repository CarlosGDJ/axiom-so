# **App Name**: LifeOS

## Core Features:

- Event Logging: Record daily events (1-3) with details like vital variable, intensity, duration, and context using an intuitive input card.
- Financial Transaction Recording: Log financial transactions with details such as category, amount, and impulsiveness using a dedicated input card.
- Relationship Interaction Tracking: Record interactions with people, noting the type and outcome, using a simple input card.
- Pattern Analysis & KPI Calculation: Analyze logged data to identify patterns, calculate KPIs (scores for variables and areas of life), and determine an overall state (OK/RISK/CRITICAL).
- Personalized Protocol Recommendation: The AI tool recommends actionable protocols based on the detected global state and dominant variables.
- Data Visualization Dashboard: Display key metrics, trends, and insights through interactive charts (score by area, daily score trends, financial breakdowns, relationship energy).
- Crisis Mode: A reduced-option interface offering protocols to promote well-being.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to represent focus, depth, and a sense of calm control.
- Background color: Very light grey (#F5F5F5), nearly white, to create a clean and modern feel.
- Accent color: Violet (#7E57C2) for interactive elements and highlights, providing a complementary contrast to the indigo.
- Body and headline font: 'Inter', a sans-serif font known for its legibility and modern aesthetic, used throughout the app for a consistent user experience.
- Use clear, minimalist icons from Material Design to represent areas of life, events, and actions, ensuring easy recognition and a consistent visual language.
- Implement a card-based layout inspired by Material UI, organizing information into distinct, manageable sections with clear separation and hierarchy.
- Employ subtle, unobtrusive animations for transitions and interactions to enhance usability without being distracting (e.g., smooth card reveals, feedback animations on button clicks).
